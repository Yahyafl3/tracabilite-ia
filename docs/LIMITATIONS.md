# Limites

## Datasets

- Synthétiques, non représentatifs d’un portefeuille réel marocain.
- Biais possibles (corrélations artificielles, régions sous-représentées).

## Crédit

- Ce n’est **pas** un modèle bancaire officiel marocain.
- Réentraînement obligatoire sur données réelles anonymisées avant usage opérationnel.

## Médical

- Estimation **indicative** uniquement.
- Ne remplace pas un diagnostic ni un professionnel de santé.
- Aucune décision automatique de traitement.

## Éducation

- Aide à l’accompagnement pédagogique.
- Pas une sanction automatique contre l’étudiant.

## IA générative

- Agents LLM informatifs seulement.
- Ne modifient pas prédiction, probabilité, facteurs techniques ni décision humaine.
